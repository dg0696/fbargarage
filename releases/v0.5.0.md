# Release v0.5.0

**Date:** 2026-09-03

## Summary

Add inventory with photos, list unlisted SKUs on eBay, store item specifics from live listings, and make Refresh from eBay incremental.

## Added

- Add-to-inventory tab, photo files, and eBay/AI field suggest
- List button on Inventory and the item page
- Item specifics (manufacturer, model, colors, sizes) plus pull from eBay
- Inventory default filter: active or not posted
- Batch tools on Inventory and Listings

## Changed

- Refresh writes only changed listings and recent orders

## Notes

Item photos stay in `data/item_photos/` and are not committed. The GitHub repo is public.
