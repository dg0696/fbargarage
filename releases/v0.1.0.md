# Release v0.1.0 - Initial Setup

**Release Date**: 2026-01-09

## Overview

Initial project setup and structure for eBay Store Financial Analysis. This release establishes the foundation for managing financial data and generating tax documents.

## Added

### Project Structure
- Git repository initialization with remote origin (https://github.com/dg0696/ebay-store.git)
- Comprehensive folder structure:
  - `scripts/` - Data processing scripts
  - `reports/` and `reports/archive/` - Generated reports and archives
  - `docs/` and `docs/archive/` - Documentation and archived docs
  - `archive/` - General file archives with manifests
  - `releases/` - Release notes
  - `logs/` - Application logs

### Configuration
- `.gitignore` file with comprehensive exclusions for Python, OS files, and generated reports
- VS Code workspace configuration (`ebay-store.code-workspace`) with:
  - Python settings and interpreter configuration
  - File exclusions for cache and OS files
  - Search exclusions for large data directories
  - Editor settings (format on save, rulers, tab size)
  - Extension recommendations (Python, CSV viewers, data analysis tools)

### Archive Functionality
- `scripts/archive_files.py` - Python script for archiving old files:
  - Moves files based on age (modification date)
  - Organizes archived files by year/month
  - Preserves file structure in archives
  - Generates JSON archive manifests
  - Logs operations to `logs/archive.log`
  - Supports dry-run mode for preview
  - Command-line arguments for flexible archiving

### Documentation
- `README.md` - Project overview, setup instructions, and usage guide
- `CHANGELOG.md` - Change tracking following Keep a Changelog format
- `docs/ARCHIVING.md` - Comprehensive archiving guide with examples
- `docs/GIT_WORKFLOW.md` - Git workflow, commit conventions, and release procedures
- `docs/DATA_STRUCTURE.md` - Documentation of financial data file formats

## Project Purpose

This project manages financial data from an eBay store selling:
- Watches
- Motorcycle parts
- Network equipment
- Video equipment

The goal is to process sales data, transaction reports, and financial records to generate comprehensive financial and tax documents for the 2025 tax year.
