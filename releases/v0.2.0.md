# Release v0.2.0

**Date:** 2026-06-07

## Summary

Adds a SQLite-backed data pipeline with CSV import, eBay API sync, DB-backed monthly reports, and parity validation against the legacy CSV analysis scripts.

## Added

- SQLite schema and local database tooling (`db/schema.sql`, `scripts/db/`)
- CSV import with idempotent upserts from `financials/f-bargarage/`
- eBay REST API client and user OAuth flow for seller data sync
- DB-backed report generators sharing logic with legacy scripts
- `scripts/run_monthly_reports.py` with `--from-db` and `--from-csv` modes
- `scripts/reports/compare_reports.py` for CSV vs DB parity validation
- `scripts/analyze_all_orders.py` for store and SKU all-orders reports
- `.env.example`, `requirements.txt`, and OAuth helper scripts
- Documentation: `docs/REPORTING.md`, updated README and DATA_STRUCTURE

## Changed

- Financial source files reorganized under `financials/f-bargarage/`
- `scripts/analyze_sku_financials.py` report formatting aligned for CSV/DB parity
- `.gitignore` updated for database files, compare temp dirs, and Cursor config

## Validation

Jan–May 2026 reports verified identical between `--from-csv` and `--from-db` using `compare_reports.py`.

## Upgrade

```bash
pip install -r requirements.txt
python scripts/db/init_db.py
python scripts/db/import_csv.py --all
python scripts/run_monthly_reports.py --year 2026 --month 5 --from-db
```
